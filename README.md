# FinFlow - เว็บแอพพลิเคชันบันทึกรายรับ-รายจ่าย (Google Sheets Integration)

เว็บแอพพลิเคชันสำหรับบันทึกรายรับและรายจ่ายส่วนบุคคล ดีไซน์ระดับพรีเมียม สวยงาม ทันสมัย รองรับทั้ง **โหมดมืด (Dark Mode)** และ **โหมดสว่าง (Light Mode)** พร้อมเชื่อมต่อฐานข้อมูล **Google Sheets** แบบเรียลไทม์

---

## 🎨 ธีมและการออกแบบ (Design Theme)
- **โทนสีหลัก**: สีดำ (Obsidian/Charcoal), สีน้ำเงิน (Electric/Royal Blue), สีเขียว (Emerald/Mint Green), สีขาว (Crisp White), และสีแดงกุหลาบ (Rose Red สำหรับรายจ่าย)
- **โหมดการแสดงผล**: รองรับการสลับระหว่าง **Dark Mode** และ **Light Mode** พร้อมจำค่าที่ผู้ใช้เลือก
- **ความสวยงามระดับพรีเมียม**: ใช้ Glassmorphism, เงาเรืองแสงแบบไดนามิก (Ambient Glow), แอนิเมชันนุ่มนวล และฟอนต์ภาษาไทย **Prompt** + **Plus Jakarta Sans**
- **Responsive**: รองรับการใช้งานทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน (พร้อมปุ่ม Floating Action Button สำหรับมือถือ)

---

## 🚀 ฟีเจอร์หลัก (Key Features)

1. **Dashboard & สรุปภาพรวมทางการเงิน**
   - การ์ดแสดง **ยอดเงินคงเหลือสุทธิ**, **รายรับทั้งหมด**, **รายจ่ายทั้งหมด**, และ **อัตราการออม (% Savings Rate)**
   - สลับดูข้อมูลได้ทั้งแบบ **รายเดือน**, **รายวัน**, และ **ทั้งหมด (All Time)** พร้อมปุ่มเลื่อนดูเดือน/วันก่อนหน้า-ถัดไป
   - ระบบ **ติดตามงบประมาณรายเดือน (Budget Tracker)** พร้อมแจ้งเตือนเมื่อใช้เงินใกล้เต็มงบ

2. **กราฟและการวิเคราะห์ (Interactive Analytics)**
   - กราฟแท่งเปรียบเทียบแนวโน้ม **รายรับ vs รายจ่าย** รายวัน/รายสัปดาห์
   - กราฟวงกลมโดนัท (Doughnut Chart) แสดง **สัดส่วนหมวดหมู่ค่าใช้จ่าย / รายรับ** พร้อมตารางแจกแจงเปอร์เซ็นต์

3. **การจัดการรายการธุรกรรม (Transactions Management)**
   - สลับประเภท **รายรับ (+) / รายจ่าย (-)** ได้สะดวกรวดเร็ว
   - หมวดหมู่พร้อมไอคอนและสีสันสวยงาม (อาหาร, เดินทาง, ช้อปปิ้ง, ที่พัก, สุขภาพ, บันเทิง, เงินเดือน, ฟรีแลนซ์ ฯลฯ)
   - ปุ่มลัดเพิ่มจำนวนเงินด่วน (`+50`, `+100`, `+500`, `+1,000`)
   - ระบุช่องทางการเงิน (เงินสด, ธนาคาร, พร้อมเพย์, บัตรเครดิต, TrueMoney)
   - ค้นหา (Search) และกรองรายการตามประเภทและหมวดหมู่
   - แก้ไข (Edit) และลบ (Delete) รายการได้ง่ายดาย

4. **การเชื่อมต่อกับ Google Sheets (Google Sheets Integration)**
   - บันทึกข้อมูลลง Google Sheet อัตโนมัติทันทีที่เพิ่มหรือลบรายการ
   - ปุ่ม **ทดสอบการเชื่อมต่อ (Test Connection)**
   - ปุ่ม **ส่งข้อมูลทั้งหมดขึ้น Google Sheet (Sync All to Sheet)**
   - ปุ่ม **ดึงข้อมูลจาก Google Sheet (Fetch from Sheet)**
   - ทำงานแบบ Offline First (เก็บในเครื่องก่อน แม้ไม่มีเน็ตก็ไม่หลุด)

5. **การสำรองและกู้คืนข้อมูล (Backup & Export)**
   - ส่งออกข้อมูลเป็นไฟล์ **CSV (Excel UTF-8 BOM รองรับภาษาไทย)**
   - ส่งออกและนำเข้าไฟล์ **JSON Backup**
   - โหลดข้อมูลตัวอย่างสำหรับทดสอบระบบ (Demo Data)

## 📋 วิธีการเชื่อมต่อกับ Google Sheets

1. **ใส่โค้ด Google Apps Script**:
   - ไปที่ [Google Apps Script](https://script.google.com) หรือเปิด Google Sheet แล้วไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
   - ลบโค้ดเดิมทั้งหมด แล้วนำโค้ดจากไฟล์ `google-apps-script.js` (หรือกดคัดลอกได้โดยตรงจากหน้าต่างตั้งค่าในเว็บ) ไปวางแทนที่
   - กดปุ่ม **บันทึก (Save 💾)**
2. **Deploy เว็บแอป (Web App)**:
   - กดปุ่ม **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - เลือกประเภท: **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ (Execute as): **ตัวฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้เว็บบันทึกข้อมูลได้)*
   - กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** และให้สิทธิ์การเข้าถึง (Authorize access)
   - คัดลอก **URL ของเว็บแอป (Web app URL)**
3. **นำมาใส่ในหน้าตั้งค่าของ FinFlow**:
   - **Apps Script URL**: ใส่ URL เว็บแอปที่ได้จากการ Deploy
   - **Google Sheet ID / URL**: ใส่ ID หรือลิงก์ URL ของ Google Sheet แผ่นที่คุณต้องการใช้งาน
   - กดปุ่ม **บันทึก** แล้วกด **ทดสอบ** ได้ทันที!
